Import Employees (CSV or Excel)

Columns: name, region, status, productivity, productivityJul, productivityAvg3m, visits, completedTasks, projects. Productivity figures are plain numbers you enter — not percentages. Header names are matched flexibly (e.g. "Region" or "July"). Rows with a region but no name are treated as region-level totals (also add an "employeeCount" column) — useful when you only have aggregate numbers for a region, not individual employees.

Architecture Notes

This is the client application layer, ready for a backend replacement.
The data model, region geometry, and settings are stored per-browser and ready to be swapped for real API calls. Employee, region, and settings schemas are stable and additive.
